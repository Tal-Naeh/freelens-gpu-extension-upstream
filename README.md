# freelens-gpu-extension

Freelens extension for GPUs: per-pod and per-device utilisation, VRAM, power
and health from dcgm-exporter or a per-process exporter, read through the
Kubernetes API server with zero cluster footprint.

This repository is being set up. The extension code is being moved here from
https://github.com/Tal-Naeh/freelens-gpu-extension, where it was originally
developed by Tal Naeh, who maintains it here as well.
